# UX-02 · Wireframe từng phần (ASCII, mobile 390 px)

Chỉ minh hoạ bố cục và thứ bậc nội dung, chưa phải thiết kế hình ảnh cuối.

┌──────────────────────┐
│                      │
│     (hoạ tiết)       │

│        &             │
│     Mai Hương        │
│                      │
│   24 · 11 · 2026     │
│   Thân mời bạn       │
│                      │
│    [ Mở thiệp ]      │
└──────────────────────┘
```

## 4 · Album
```
│  ALBUM ẢNH CƯỚI      │
│ ◀ [ ảnh ][ảnh][ảnh ▶ │   vuốt ngang, snap
│        ● ○ ○ ○       │
```
Lightbox: ảnh lớn giữa, ✕ góc phải, ◀ ▶ hai bên, chỉ số "3 / 8".
## 5 · Đếm ngược + lịch
```
│  CÙNG ĐẾM NGƯỢC      │
│  Lễ Vu Quy           │
│  [ 23 ][ 04 ][ 12 ][ 30 ] │
│   ngày  giờ  phút  giây   │
│  Lễ Thành Hôn  (tương tự) │
│  THÁNG 11 · 2026     │
│  CN T2 T3 T4 T5 T6 T7│
│  ...        (24 ●)   │
│  [ Thêm vào lịch ▾ ] │  → Google Calendar | Tải .ics
```
## 6 · Chỉ đường
```
